Huffman Coding

Category: Compression Difficulty: ★★★★★ File: huffman.c

Description

Build a frequency table of the input, construct a binary Huffman tree (lowest frequency nodes merged first), assign a bit code to each character by tree path, and encode the string as a bitstream. Implement decoding by walking the same tree bit by bit.

Function Prototypes

t_huff_code *ft_huffman_encode(char *str, int *out_bitlen);
char *ft_huffman_decode(t_huff_code *tree, char *bits, int bitlen);

Constraints

  • Define your own t_huff_node / t_huff_code structs in a header alongside the .c file.
  • You must serialize/store enough of the tree (or frequency table) that decode does not need the original string.
  • Tie-breaking between equal-frequency nodes must be deterministic (e.g. by insertion order) so encode is reproducible.

Examples

Input: aaabbc
Output: frequencies a:3 b:2 c:1 -> shorter codes for 'a', longer for 'c'

Turn-in

A single file named huffman.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
