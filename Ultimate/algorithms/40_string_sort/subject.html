Sorting an Array of Strings

Category: Combined Difficulty: ★★☆☆☆ File: string_sort.c

Description

Implement two classic sorting algorithms operating on an array of strings, comparing lexicographically: bubble sort (simple, O(n^2), for comparison) and quicksort (partition-based, average O(n log n)).

Function Prototypes

void ft_bubble_sort_strs(char **strs, int count);
void ft_quicksort_strs(char **strs, int lo, int hi);

Constraints

  • Sort must be in place, swapping pointers in the array rather than copying string contents.
  • quicksort's partition scheme (Lomuto or Hoare) is your choice, but must be stated in a comment.
  • Must handle an already-sorted array and an array with duplicate strings without infinite recursion.

Examples

Input: ["banana","apple","cherry"]
Output: ["apple","banana","cherry"]

Turn-in

A single file named string_sort.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
