Tokenizer / Split

Category: String Analysis Difficulty: ★★☆☆☆ File: tokenizer.c

Description

Split a string into an array of tokens, where any character in charset is treated as a separator; consecutive separators must not create empty tokens.

Function Prototype

char **ft_tokenize(char *str, char *charset);

Constraints

  • Return value is a NULL-terminated array of malloc'd strings.
  • On malloc failure partway through, free everything allocated so far before returning NULL.
  • An input string of only separators must return a valid array containing just the NULL terminator, not a crash.

Examples

Input: (" the, sky is,blue ", " ,")
Output: ["the", "sky", "is", "blue"]

Turn-in

A single file named tokenizer.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
