Palindrome Check

Category: String Analysis Difficulty: ★☆☆☆☆ File: palindrome.c

Description

Check whether a string reads the same forwards and backwards using a two-pointer approach (one pointer at each end, moving inward).

Function Prototype

int ft_is_palindrome(char *str);

Constraints

  • Must run in O(n) with O(1) extra space -- no reversing into a new string.
  • Decide and document whether case and non-alphanumeric characters are ignored.
  • Empty string and single-character strings must both return true.

Examples

Input: racecar
Output: 1 (true)
Input: hello
Output: 0 (false)

Turn-in

A single file named palindrome.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
