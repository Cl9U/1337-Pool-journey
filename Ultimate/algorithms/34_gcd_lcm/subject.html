GCD / LCM (Euclidean Algorithm)

Category: Integer Difficulty: ★☆☆☆☆ File: gcd_lcm.c

Description

Implement the greatest common divisor using the Euclidean algorithm (recursive or iterative), and compute the least common multiple from it using lcm(a,b) = |a*b| / gcd(a,b).

Function Prototypes

int ft_gcd(int a, int b);
long ft_lcm(int a, int b);

Constraints

  • Must handle 0 as an input (gcd(0, n) = n).
  • Use a long (or wider) for the intermediate a*b product in ft_lcm to avoid overflow.
  • gcd/lcm of negative numbers should be returned as positive values by convention (document it).

Examples

Input: (48, 18) gcd
Output: 6
Input: (4, 6) lcm
Output: 12

Turn-in

A single file named gcd_lcm.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
