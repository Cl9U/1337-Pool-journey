Move-To-Front

Category: Compression Difficulty: ★★☆☆☆ File: mtf.c

Description

Maintain a list of the 256 possible byte values. For each input character, output its current index in the list, then move that character to the front of the list. Implement the decode that reconstructs the original string from the list of indices using the same front-moving rule.

Function Prototypes

int *ft_mtf_encode(char *str, int *out_len);
char *ft_mtf_decode(int *codes, int len);

Constraints

  • The alphabet must start ordered 0..255 (ASCII order) before encoding begins.
  • Encode must output one int per input character into a malloc'd array; store the length via out_len.
  • Decode must rebuild the exact original byte string from the same alphabet, starting fresh.

Examples

Input: banana
Output: encode -> list of ints, one per char, based on symbol rank

Turn-in

A single file named mtf.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
