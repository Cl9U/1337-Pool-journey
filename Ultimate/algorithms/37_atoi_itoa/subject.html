atoi / itoa Reimplementation

Category: Integer Difficulty: ★★☆☆☆ File: atoi_itoa.c

Description

Reimplement the standard atoi (skip leading whitespace, handle an optional sign, parse digits until a non-digit) and itoa (convert an int, including INT_MIN, into a malloc'd string).

Function Prototypes

int ft_atoi(char *str);
char *ft_itoa(int nbr);

Constraints

  • ft_itoa must correctly handle INT_MIN, which cannot be negated into a positive int directly.
  • ft_atoi must stop parsing at the first non-digit character rather than erroring out.
  • Neither function may call the real atoi/itoa from libc.

Examples

Input: " -42abc" atoi
Output: -42
Input: itoa(-2147483648)
Output: "-2147483648"

Turn-in

A single file named atoi_itoa.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
