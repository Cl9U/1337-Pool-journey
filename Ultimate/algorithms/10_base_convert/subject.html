Arbitrary Base Conversion

Category: Compression Difficulty: ★★☆☆☆ File: base_convert.c

Description

Convert a base-10 integer into a string representation using an arbitrary supplied base/alphabet (e.g. base='01' for binary, base='0123456789ABCDEF' for hex), and implement the inverse parser that reads such a string back into a long.

Function Prototypes

char *ft_convert_base(long nbr, char *base);
long ft_parse_base(char *str, char *base);

Constraints

  • The base string defines both the radix (its length) and which symbol represents which digit.
  • Validate the base: at least 2 unique characters, no duplicate characters, no '+' or '-' inside it.
  • Handle negative numbers with a leading '-' on output/input.

Examples

Input: (42, "01")
Output: 101010
Input: (255, "0123456789ABCDEF")
Output: FF

Turn-in

A single file named base_convert.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
