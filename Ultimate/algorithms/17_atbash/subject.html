Atbash Cipher

Category: Ciphers Difficulty: ★☆☆☆☆ File: atbash.c

Description

Implement the Atbash cipher: reverse the alphabet, so 'a' maps to 'z', 'b' to 'y', and so on. Like ROT13, it is its own inverse.

Function Prototype

char *ft_atbash(char *str);

Constraints

  • Only alphabetic characters are transformed; case is preserved.
  • One function must handle both encode and decode.
  • No lookup table of 26 hardcoded pairs -- compute the mapping arithmetically.

Examples

Input: Hello
Output: Svool

Turn-in

A single file named atbash.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
