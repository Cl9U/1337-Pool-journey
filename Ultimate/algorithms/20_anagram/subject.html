Anagram Check

Category: String Analysis Difficulty: ★☆☆☆☆ File: anagram.c

Description

Determine whether two strings are anagrams of each other -- i.e. contain exactly the same characters with the same multiplicities, ignoring order.

Function Prototype

int ft_is_anagram(char *s1, char *s2);

Constraints

  • Decide and document whether the check is case-sensitive and whether spaces count as characters.
  • Must return 0 immediately if the two strings have different lengths (after any normalization).
  • Use a frequency array (e.g. int counts[256]) rather than nested loops for O(n) complexity.

Examples

Input: ("listen", "silent")
Output: 1 (true)
Input: ("hello", "world")
Output: 0 (false)

Turn-in

A single file named anagram.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
