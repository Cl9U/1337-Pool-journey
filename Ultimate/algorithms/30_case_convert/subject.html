Case Conversion

Category: String Analysis Difficulty: ★☆☆☆☆ File: case_convert.c

Description

Implement four case-transformation variants on a string: all uppercase, all lowercase, capitalize the first letter of each word, and toggle the case of every letter.

Function Prototypes

char *ft_to_upper(char *str);
char *ft_to_lower(char *str);
char *ft_capitalize(char *str);
char *ft_toggle_case(char *str);

Constraints

  • Only ASCII letters are affected; digits, punctuation and spaces pass through unchanged.
  • ft_capitalize must define what counts as a 'word boundary' (whitespace) and apply it consistently.
  • All four must return a newly allocated string, leaving the input untouched.

Examples

Input: ("hello World") upper
Output: HELLO WORLD
Input: ("hello world") capitalize
Output: Hello World
Input: ("Hello") toggle
Output: hELLO

Turn-in

A single file named case_convert.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
