Roman Numeral Conversion

Category: Integer Difficulty: ★★★☆☆ File: roman.c

Description

Convert a positive integer (1-3999) into its Roman numeral representation using the standard subtractive notation (IV, IX, XL, ...), and implement the reverse parser.

Function Prototypes

char *ft_int_to_roman(int nbr);
int ft_roman_to_int(char *str);

Constraints

  • Values outside 1-3999 should return NULL / a defined error value (document your choice).
  • ft_int_to_roman must use a lookup table of value/symbol pairs, greedily subtracting, not a giant if/else chain.
  • ft_roman_to_int must handle subtractive pairs correctly (e.g. IV = 4, not I then V summed as 6).

Examples

Input: 3549
Output: MMMDXLIX
Input: "MCMXCIV"
Output: 1994

Turn-in

A single file named roman.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
