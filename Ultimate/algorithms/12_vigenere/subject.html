Vigenère Cipher

Category: Ciphers Difficulty: ★★★☆☆ File: vigenere.c

Description

Encrypt using a repeating keyword: each plaintext letter is shifted by the alphabet position of the corresponding key letter (key repeats/wraps to match message length). Non-alphabetic characters pass through unchanged and do not consume a key letter. Implement decryption as the inverse shift.

Function Prototypes

char *ft_vigenere_encrypt(char *str, char *key);
char *ft_vigenere_decrypt(char *str, char *key);

Constraints

  • The key index must only advance on alphabetic plaintext characters.
  • Key may contain mixed case; normalize it internally.
  • Handle key length 0 or 1 without crashing (define a sane behavior and document it).

Examples

Input: ("ATTACKATDAWN", key="LEMON")
Output: LXFOPVEFRNHR

Turn-in

A single file named vigenere.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
