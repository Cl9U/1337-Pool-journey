String / Word Reversal

Category: String Analysis Difficulty: ★☆☆☆☆ File: string_reverse.c

Description

Implement two variants: reversing all characters in a string in place, and reversing the order of words while keeping each word's letters intact (e.g. 'hello world' -> 'world hello').

Function Prototypes

char *ft_reverse_chars(char *str);
char *ft_reverse_words(char *str);

Constraints

  • ft_reverse_chars must work in place with two pointers, O(1) extra space.
  • ft_reverse_words must handle multiple consecutive spaces sanely (document your normalization choice).
  • Both must handle empty strings without crashing.

Examples

Input: ("hello") chars
Output: olleh
Input: ("the sky is blue") words
Output: blue is sky the

Turn-in

A single file named string_reverse.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
