Fibonacci (Iterative & Memoized)

Category: Integer Difficulty: ★☆☆☆☆ File: fibonacci.c

Description

Implement Fibonacci two ways: a purely iterative O(n) version with O(1) space, and a memoized version that stores previously computed results in a cache array to avoid recomputation.

Function Prototypes

long ft_fibonacci_iter(int n);
long ft_fibonacci_memo(int n, long *cache);

Constraints

  • n < 0 is invalid input; define and document a clear error behavior.
  • The iterative version must not use recursion at all.
  • The cache array passed to ft_fibonacci_memo must be pre-sized by the caller; document the expected size convention.

Examples

Input: ft_fibonacci_iter(10)
Output: 55

Turn-in

A single file named fibonacci.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
