Bracket / Parenthesis Matching

Category: Combined Difficulty: ★★☆☆☆ File: bracket_match.c

Description

Using a stack, verify that all brackets in a string -- (), [], {} -- are balanced and correctly nested. Any character that is not a bracket is ignored.

Function Prototype

int ft_brackets_match(char *str);

Constraints

  • Implement your own small stack (array-based is fine) -- no calling into unrelated libft structures.
  • Must return 0 as soon as a closing bracket doesn't match the most recently opened one.
  • A string with leftover unclosed brackets at the end must also return 0.

Examples

Input: ([{}])
Output: 1 (balanced)
Input: ([)]
Output: 0 (not balanced)

Turn-in

A single file named bracket_match.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
