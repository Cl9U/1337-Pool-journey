LZW Compression

Category: Compression Difficulty: ★★★★☆ File: lzw.c

Description

Initialize the dictionary with all single-byte values (codes 0-255). Scan the input greedily extending the current match as long as it exists in the dictionary; when it stops matching, output the code for the longest match and add match+next_char as a new dictionary entry. Implement the matching decompression logic, including the classic 'KwKwK' edge case where a code is used before it's formally added.

Function Prototypes

int *ft_lzw_compress(char *str, int *out_count);
char *ft_lzw_decompress(int *codes, int count);

Constraints

  • Dictionary must start pre-populated with entries 0-255 for all byte values.
  • New codes are assigned sequentially starting at 256.
  • Decoder must handle the special case where the encoder emits a code that doesn't exist yet in the decoder's dictionary.

Examples

Output: classic LZW textbook example -- trace it by hand first
