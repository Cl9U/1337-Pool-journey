Digit Sum / Digital Root

Category: Integer Difficulty: ★☆☆☆☆ File: digit_sum.c

Description

ft_digit_sum adds up the individual digits of a number once. ft_digital_root repeats that process until a single digit remains (e.g. 9875 -> 29 -> 11 -> 2).

Function Prototypes

int ft_digit_sum(int nbr);
int ft_digital_root(int nbr);

Constraints

  • Must handle negative numbers by working on the absolute value.
  • ft_digital_root should ideally use the O(1) modulo-9 formula as a bonus, but an iterative version is fine for mandatory.
  • nbr = 0 must return 0, not loop forever.

Examples

Input: 9875 sum
Output: 29
Input: 9875 root
Output: 2

Turn-in

A single file named digit_sum.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
