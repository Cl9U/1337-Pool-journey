LZ77 Compression

Category: Compression Difficulty: ★★★★☆ File: lz77.c

Description

Using a sliding window over already-seen input, output (offset, length, next_char) tokens: the longest match found in the window, followed by the literal character that broke the match. Implement decompression that replays the tokens against the growing output buffer.

Function Prototypes

t_lz77_token *ft_lz77_compress(char *str, int *out_count);
char *ft_lz77_decompress(t_lz77_token *tokens, int count);

Constraints

  • Define t_lz77_token { int offset; int length; char next; } in your header.
  • Window size and lookahead size are your choice, but must be documented as constants at the top of the file.
  • If no match is found, offset/length must be 0 and next holds the literal character.

Examples

Input: abcabcabc
Output: token stream should compress the repeated 'abc' after the first occurrence

Turn-in

A single file named lz77.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
