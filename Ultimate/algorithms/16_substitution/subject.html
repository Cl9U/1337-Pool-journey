Substitution Cipher

Category: Ciphers Difficulty: ★★☆☆☆ File: substitution.c

Description

Given a 26-letter key that is a permutation of the alphabet, replace each plaintext letter with the letter at the same position in the key (a->key[0], b->key[1], ...). Implement decryption as the inverse mapping.

Function Prototypes

char *ft_substitution_encrypt(char *str, char *key_alphabet);
char *ft_substitution_decrypt(char *str, char *key_alphabet);

Constraints

  • Validate that key_alphabet has exactly 26 unique alphabetic characters; return NULL otherwise.
  • Preserve case; non-alphabetic characters pass through unchanged.
  • Build the reverse lookup table for decrypt rather than searching the key linearly per character.

Examples

Input: key = "QWERTYUIOPASDFGHJKLZXCVBNM"
Output: 'hello' -> substitute each letter through the key

Turn-in

A single file named substitution.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
