Rail Fence Cipher

Category: Ciphers Difficulty: ★★★☆☆ File: rail_fence.c

Description

Write the message in a zigzag pattern across a given number of rails (rows), then read off each rail in order to produce the ciphertext. Implement the inverse: reconstruct the zigzag pattern's shape first, then place the ciphertext characters into it and read them off in original order.

Function Prototypes

char *ft_rail_fence_encrypt(char *str, int rails);
char *ft_rail_fence_decrypt(char *str, int rails);

Constraints

  • rails must be validated (>= 2); for rails <= 1 just return a copy of the input.
  • The zigzag direction must flip exactly at the top and bottom rails.
  • Decrypt must correctly handle messages whose length isn't a clean multiple of the zigzag period.

Examples

Input: ("WEAREDISCOVEREDFLEEATONCE", rails=3)
Output: WECRLTEERDSOEEFEAOCAIVDEN

Turn-in

A single file named rail_fence.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
