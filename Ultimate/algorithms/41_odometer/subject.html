Odometer-Style Combination Counter

Category: Combined Difficulty: ★★★☆☆ File: odometer.c

Description

Print every increasing combination of n distinct digits (0-9), in lexicographic order, comma-separated, using an odometer-like iterative approach (increment the rightmost position, carry/reset with the constraint that each position must stay strictly greater than the one before it).

Function Prototype

void ft_print_combn(int n);

Constraints

  • n must be validated between 1 and 10 inclusive.
  • Output must use only write(), one comma+space between combinations, and no trailing separator after the last one.
  • Must be implemented iteratively (no recursion) with explicit index-array carry logic.

Examples

Input: n=2
Output: 01, 02, 03, ..., 89

Turn-in

A single file named odometer.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
