RLE — Run-Length Encoding

Category: Compression Difficulty: ★☆☆☆☆ File: rle.c

Description

Implement run-length encoding: replace consecutive repeated characters with the character followed by its count. Implement the inverse transform as well, so that decode(encode(str)) == str for any input.

Function Prototypes

char *ft_rle_encode(char *str);
char *ft_rle_decode(char *str);

Constraints

  • A run of length 1 must still be written with a count of 1 (e.g. 'a' -> 'a1'), to keep encode/decode unambiguous.
  • Digits inside the original string are not allowed as input (assume alphabetic input only) to avoid ambiguity with the encoded count.
  • Return a newly malloc'd string. Return NULL on malloc failure.

Examples

Input: aaabbc
Output: a3b2c1
Input: aaabbc (decode input)
Output: aaabbc

Turn-in

A single file named rle.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
