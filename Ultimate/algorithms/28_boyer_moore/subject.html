Boyer-Moore Substring Search

Category: String Analysis Difficulty: ★★★★☆ File: boyer_moore.c

Description

Implement the Boyer-Moore algorithm using at least the bad-character heuristic: precompute the last occurrence of each byte in the needle, then scan the needle right-to-left against the haystack, skipping ahead using the bad-character table on a mismatch.

Function Prototype

int ft_boyer_moore_search(char *haystack, char *needle);

Constraints

  • The bad-character table must cover all 256 byte values, defaulting to -1 (not present).
  • The good-suffix heuristic is optional bonus; bad-character alone is enough to pass mandatory.
  • Return the index of the first match, or -1 if not found.

Examples

Input: ("ABAAABCD", "ABC")
Output: 4

Turn-in

A single file named boyer_moore.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
