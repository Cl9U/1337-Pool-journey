RLE + Reverse Pipeline

Category: Combined Difficulty: ★★☆☆☆ File: rle_reverse_pipeline.c

Description

Chain two transforms into one pipeline: first run-length-encode the input, then reverse the resulting encoded string, and return the final result. This is an exercise in composing previously built primitives cleanly.

Function Prototype

char *ft_pipeline_rle_reverse(char *str);

Constraints

  • You may internally reuse your RLE encode/reverse functions from exercises 01 and 24, or reimplement locally.
  • Intermediate buffers must be freed once no longer needed -- no leaking the RLE-encoded intermediate string.
  • Document the exact order of operations at the top of the file.

Examples

Input: aaabbc
Output: RLE -> 'a3b2c1', then reversed -> '1c2b3a'

Turn-in

A single file named rle_reverse_pipeline.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
