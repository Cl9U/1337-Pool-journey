ROT13

Category: Ciphers Difficulty: ★☆☆☆☆ File: rot13.c

Description

Implement ROT13, the special case of Caesar cipher with a fixed shift of 13. Because 13 is half of 26, the same function must both encode and decode.

Function Prototype

char *ft_rot13(char *str);

Constraints

  • Only alphabetic characters are transformed; everything else is untouched.
  • One single function handles both directions -- do not write a separate decode function.
  • No use of atoi/itoa or external ctype-heavy shortcuts beyond what's normorm-allowed.

Examples

Input: Why did the chicken cross the road?
Output: Jul qvq gur puvpxra pebff gur ebnq?

Turn-in

A single file named rot13.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
