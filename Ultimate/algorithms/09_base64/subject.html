Base64 Encode / Decode

Category: Compression Difficulty: ★★★☆☆ File: base64.c

Description

Encode arbitrary binary data 3 bytes at a time into 4 base64 characters using the standard alphabet (A-Z a-z 0-9 + /), padding with '=' when the input length isn't a multiple of 3. Implement the reverse to recover the original bytes.

Function Prototypes

char *ft_base64_encode(unsigned char *data, int len);
unsigned char *ft_base64_decode(char *b64, int *out_len);

Constraints

  • Use the standard RFC 4648 alphabet, not URL-safe variant.
  • Padding with '=' must be correctly applied for 1 or 2 leftover bytes.
  • Decoder must reject or skip whitespace/newlines gracefully (your choice, documented).

Examples

Input: Man
Output: TWFu
Input: Ma
Output: TWE=

Turn-in

A single file named base64.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
