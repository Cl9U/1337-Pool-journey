Longest Common Substring

Category: String Analysis Difficulty: ★★★☆☆ File: lcs_substring.c

Description

Find the longest contiguous run of characters that appears in both input strings, using dynamic programming (a 2D table where table[i][j] holds the length of the common substring ending at s1[i-1] and s2[j-1]).

Function Prototype

char *ft_longest_common_substring(char *s1, char *s2);

Constraints

  • Must return an empty string (not NULL) if there is no common substring.
  • If multiple substrings share the maximum length, returning any one of them is acceptable.
  • Target O(n*m) time using a DP table, not brute-force triple nested loops.

Examples

Input: ("abcdef", "zabcf")
Output: abc

Turn-in

A single file named lcs_substring.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
