Longest Common Subsequence

Category: String Analysis Difficulty: ★★★☆☆ File: lcs_subsequence.c

Description

Find the longest sequence of characters that appears in both strings in the same relative order, but not necessarily contiguously, using the classic DP recurrence over a 2D table.

Function Prototype

char *ft_longest_common_subsequence(char *s1, char *s2);

Constraints

  • Must return an empty string if there is no common subsequence.
  • Reconstruct the actual subsequence by walking back through the DP table, not just its length.
  • Target O(n*m) time and space (or O(min(n,m)) space as a bonus optimization).

Examples

Input: ("ABCBDAB", "BDCABA")
Output: BCBA (length 4, one valid answer)

Turn-in

A single file named lcs_subsequence.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
