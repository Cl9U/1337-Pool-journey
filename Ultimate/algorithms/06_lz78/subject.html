LZ78 Compression

Category: Compression Difficulty: ★★★★☆ File: lz78.c

Description

Build a dictionary of previously seen substrings, each indexed by an integer. For each new input segment, output (dictionary_index, next_char) where dictionary_index is the longest existing dictionary entry matched, then add the new (entry+char) as a fresh dictionary entry. Implement decompression by rebuilding the dictionary the same way.

Function Prototypes

t_lz78_token *ft_lz78_compress(char *str, int *out_count);
char *ft_lz78_decompress(t_lz78_token *tokens, int count);

Constraints

  • Dictionary index 0 must mean 'empty prefix'.
  • You may implement the dictionary as a simple growable array of strings; a trie is optional but not required.
  • Decompression must reconstruct the dictionary identically and in the same order as compression.

Examples

Input: ababab
Output: dictionary grows: a, b, ab, aba... tokens reference earlier entries

Turn-in

A single file named lz78.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
