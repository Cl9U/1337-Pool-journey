Luhn Algorithm (Checksum Validation)

Category: Integer Difficulty: ★★☆☆☆ File: luhn.c

Description

Implement the Luhn checksum used to validate credit-card-style numbers: starting from the rightmost digit, double every second digit, subtract 9 if the result exceeds 9, then check whether the total sum is a multiple of 10.

Function Prototype

int ft_luhn_check(char *number);

Constraints

  • Input is a string of digits (may include spaces to be ignored, document your choice).
  • Return 1 for a valid checksum, 0 for invalid, and a defined error value for malformed input (non-digit characters).
  • Must work for numbers of arbitrary length without overflowing an int (accumulate the sum only, not the whole number).

Examples

Input: "4539578763621486"
Output: 1 (valid)
Input: "1234567812345678"
Output: 0 (invalid)

Turn-in

A single file named luhn.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
