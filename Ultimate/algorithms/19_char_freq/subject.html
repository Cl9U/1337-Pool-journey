Character Frequency (occurrence order)

Category: String Analysis Difficulty: ★☆☆☆☆ File: char_freq.c

Description

Count occurrences of each character in the input and print each distinct character with its count, in the order each character first appears (not alphabetical order).

Function Prototype

void ft_count_alpha(char *str);

Constraints

  • Case-sensitive counting: 'a' and 'A' are different characters.
  • Only characters actually present in the input are printed -- no zero counts.
  • Output format is your choice but must be consistent, e.g. 'c: n' per line.

Examples

Input: banana
Output: b: 1\na: 3\nn: 2

Turn-in

A single file named char_freq.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
