Rabin-Karp Substring Search

Category: String Analysis Difficulty: ★★★☆☆ File: rabin_karp.c

Description

Implement substring search using rolling hashes: compute a hash of the needle and of each window of the haystack, comparing hashes first and only doing a full character comparison when hashes match (to guard against collisions).

Function Prototype

int ft_rabin_karp_search(char *haystack, char *needle);

Constraints

  • The rolling hash update must be O(1) per shift (recompute from the previous hash, not from scratch).
  • Choose a reasonable modulus/base to limit collisions and document them at the top of the file.
  • On a hash collision without an actual match, must continue searching, not return a false positive.

Examples

Input: ("GEEKS FOR GEEKS", "GEEK")
Output: 0

Turn-in

A single file named rabin_karp.c in this folder, Norminette-compliant, with no memory leaks (check with a leak checker on all malloc'd returns).
